I tested whether pouring and consumption methods change how much people enjoy soft drinks. Using a linear regression with an interaction term, the overall model wasn’t statistically significant (p = 0.1026), a result echoed by a permutation test (p = 0.0967).

Partial F-tests with Bonferroni adjustment also found no reliable effects: pouring method (p = 0.26), consumption method (p = 0.09), and their interaction (p = 0.496) were all non-significant. Exploratory coefficient checks suggested possible differences by level—“leave in can/bottle” (p ≈ 0.031) and “via straw” (p ≈ 0.049)—but these did not survive multiple-comparison correction nor overturn the non-significant model-level result; “straight into center” showed no effect (p = 0.422).

Overall, we find no statistically robust evidence that pouring or consumption method meaningfully alters enjoyment ratings. Future work should increase power, pre-register contrasts, and consider additional covariates (e.g., carbonation, temperature, brand) or mixed-effects designs to capture participant heterogeneity and reduce Type I/II error risk.
